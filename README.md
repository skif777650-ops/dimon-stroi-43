# Dimon-Stroi 43

Публичный адаптивный сайт: https://skif777650-ops.github.io/dimon-stroi-43/
Статический HTML/CSS/JS, сборка не требуется. Pages main / root, .nojekyll.

## Заявки
Форма отправляет JSON на отдельный HTTPS API https://dimon-stroi-43-leads.proud-root-3195.chatgpt.site/api/leads . API сохраняет заявку в Google Sheets через защищённый приёмник и отправляет Telegram-уведомление с тем же номером. Секреты хранятся только в переменных окружения сервера Sites. При частичной доставке форма показывает явную ошибку; повтор с тем же номером защищает запись таблицы от дубликатов.

## Интерфейс
Вступление, 5 этапов строительства, обратная прокрутка, адаптив и reduced-motion.

## Ресурсы
Изображения — концептуальная визуализация. Manrope: SIL OFL, см. assets/Manrope-OFL.txt. Контур области: https://github.com/simp37/Russia_geoJSON/blob/master/Kirovskaya.geojson
