# Dimon-Stroi 43

Публичный адаптивный сайт компании. Статический HTML/CSS/JavaScript, сборка и зависимости не требуются.

## Публикация
GitHub Pages: ветка main, папка / (root). .nojekyll отключает Jekyll. Все ресурсы имеют относительные пути и работают под /dimon-stroi-43/.

## Возможности
Вступительная анимация на прокрутке, пять этапов строительства, обратная прокрутка, адаптив и prefers-reduced-motion.

## Для отдельного размещения
Отправка заявок требует HTTPS-сервера с POST /api/leads: валидация и ограничение частоты запросов, серверная запись в Google Sheets через защищённый Apps Script, секретный ключ. Возможная отправка в Telegram также требует серверного хранения токена и chat ID. Эти компоненты и секреты в репозиторий не включены.
На Pages форма явно сообщает, что отправка не подключена. Публикация не изменяет локальную рабочую интеграцию.

## Ресурсы
Изображения — концептуальная визуализация. Шрифт Manrope — SIL Open Font License, см. assets/Manrope-OFL.txt. Контур Кировской области: https://github.com/simp37/Russia_geoJSON/blob/master/Kirovskaya.geojson
